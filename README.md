# Sistema de Restaurante e Cardápio 🍽️

Projeto desenvolvido durante os cursos da **Alura**:
- **Python: aplicando a Orientação a Objetos**
- **Python: avançando na Orientação a Objetos e consumo de API**

Este projeto representa meu **primeiro contato prático com Programação Orientada a Objetos (POO) em Python**, aplicando conceitos fundamentais na construção de um sistema simples de gerenciamento de restaurantes e cardápio.

---

## Aprendizado

Este projeto foi desenvolvido com foco no aprendizado dos fundamentos de **Programação Orientada a Objetos em Python**, consolidando conceitos como encapsulamento, herança, polimorfismo e classes abstratas.

---

## Funcionalidades

- Cadastro de restaurantes
- Ativação e desativação de restaurantes
- Sistema de avaliação com cálculo da média
- Criação de cardápio com:
  - Pratos
  - Bebidas
  - Sobremesas
- Aplicação de descontos específicos para cada tipo de item
- Exibição do cardápio no terminal

---

## Conceitos aplicados

- Programação Orientada a Objetos (POO)
- Encapsulamento
- Herança
- Polimorfismo
- Classes abstratas (`ABC`)
- Organização de código em módulos e pacotes
